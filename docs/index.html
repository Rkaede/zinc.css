A classless CSS framework · 0.1.0-next.0

zinc.css

One stylesheet that styles semantic HTML as it is. Write plain markup with no class names, and zinc sets it as one column of text, with section labels in the margin and colour kept for what you focus, check or choose.

In brief

zinc is a single CSS file. It styles elements such as <button>, <table>, <article> and <details> directly, so there is nothing to learn beyond HTML. There is no JavaScript, no preprocessor and no build step on your side.

  • Text sits on one left edge. On a wide screen, each section's heading moves into a margin as a label that stays in view.
  • Links and buttons are ink. The accent colour marks only state: focus, checked controls, chosen options and progress.
  • Light and dark modes follow the system, or you set one. Three accents and a beige paper are built in.
  • The few variants (button styles, sizes, switches, segmented controls) are attributes and ARIA roles, never classes.

Install

Use the next tag. This site documents 0.1.0-next.0, a pre-release published under the npm next tag. An unpinned URL or a plain npm install zinc.css gets latest, which is still an older version with a different look. Ask for @next, or pin @0.1.0-next.0.

From a CDN

Add one <link> to the <head>. jsDelivr and unpkg both serve the package:

<!-- jsDelivr -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/zinc.css@next/zinc.css" />

<!-- unpkg -->
<link rel="stylesheet" href="https://unpkg.com/zinc.css@next/zinc.css" />

Each package also has a minified build, zinc.min.css.

Pin a version

The @next tag moves when a new pre-release comes out. For anything past a prototype, pin the exact version so the page can't change under you:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/zinc.css@0.1.0-next.0/zinc.min.css" />

From npm

npm install zinc.css@next

The package holds zinc.css and zinc.min.css at its top level. Link the file from node_modules/zinc.css/, or import it with a bundler that handles CSS:

import "zinc.css";       /* zinc.css */
import "zinc.css/min";   /* zinc.min.css */
