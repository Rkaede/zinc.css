Theming

Three attributes on <html> pick the mode, the accent and the paper. Everything else is a CSS custom property you can override.

Theme hooks

data-mode
light, dark
Forces a mode. Leave it off to follow the system setting. A forced mode also sets color-scheme, so native controls, scrollbars and light-dark() colours follow it.
data-accent
electric, forest, violet
Picks the accent. Electric, a dusty blue, is the default; forest is green and violet is purple. Each has a light and a dark shade.
data-paper
beige
Swaps the white page for a pale green-beige paper, and gives cards a lighter fill in place of their outline. Works on <html> or <body>. In dark mode the page stays dark grey; cards still take a fill instead of an outline.
<html lang="en" data-mode="dark" data-accent="forest" data-paper="beige">

    The accent

    The accent marks state, and nothing else: the focus ring, a checked checkbox or radio, a switch that is on, a chosen choice card or segment, the range thumb, progress and meter bars, and a focused text field. It also tints <mark>, <ins> and selected text, colours the text cursor, and shows on a link under the mouse.

    Links and buttons are ink. A link is the text colour with a hairline underline; a button is a dark fill in light mode and a light one in dark mode. A command looks like a command, and colour stays free to say "this one is chosen".

    Every built-in accent meets WCAG AA in both modes: at least 4.5:1 as text against the page, and --on-accent at least 4.5:1 on an accent fill. The focus ring clears 3:1 against the page and against fields.

    Your own accent

    Name an accent of your own in your stylesheet, after zinc, and give it a light and a dark shade with light-dark(). The browser picks the shade from the mode, so you need no rules for dark mode.

    :root[data-accent="teal"] {
  --accent: light-dark(#0f766e, #2dd4bf);
  --on-accent: light-dark(#ffffff, #101311);
}
    <html lang="en" data-accent="teal">

    To change the default accent instead, set the same two properties on plain :root. A data-accent attribute still wins over that, because :root[data-accent] is the stronger selector.

    • Keep the accent at 4.5:1 or more against the page in each mode (white, or #141615 in dark), and --on-accent at 4.5:1 or more on the accent.
    • The soft shades zinc mixes from the accent (the text-field halo, the <ins> tint, the selection) follow it automatically.
    • The danger colour works the same way: set --danger and --on-danger as light-dark() pairs.

    The ?accent= switch on these docs accepts any name, so once your stylesheet defines one, ?accent=teal previews it.

    Tokens

    Override any of these on :root in a stylesheet loaded after zinc. Defaults are the light, white-page values.

    Colour

    --accent
    light-dark(#3559c7, #93aaff)
    The state colour: focus, checked, chosen, progress.
    --on-accent
    light-dark(#ffffff, #101311)
    Marks and text on an accent fill: the tick, the radio dot, a chosen segment's label.
    --danger
    light-dark(#b93a2c, #f2877a)
    Danger buttons, invalid fields, required marks.
    --on-danger
    light-dark(#ffffff, #101311)
    Text on a danger button.

    Shape and layout

    --radius
    8px
    Corners of fields, buttons, choice cards, images and video.
    --radius-lg
    12px
    Corners of code blocks, cards and notes. The dialog adds 2px.
    --width
    42rem
    The text column.
    --measure
    38rem
    Where paragraphs, list items, quotes and captions wrap, about 75 characters. Tables, entry lists and blocks use the whole column.
    --gutter
    clamp(1.25rem, 5vw, 2.5rem)
    Page padding on each side.
    --rail
    11rem
    The margin that holds section labels from 56rem wide.
    --rail-gap
    3rem
    The space between that margin and the column.
    --bleed
    1.25rem
    How far code blocks, notes and cards reach past the text edge on each side. Up to 40rem wide it equals --gutter, so they run to the screen edges.
    --section-gap
    4rem
    Space between top-level sections, below the page header and above a footer. 3.25rem up to 40rem wide.

    zinc sets --bleed and --section-gap again inside a max-width: 40rem media query, so an override on plain :root after zinc applies at every width.

    Neutrals

    The page colours, in light, dark and on the beige paper. Where no beige value is given, the beige paper keeps the light one.

    --bg
    #ffffff light, #141615 dark, #f3f5f0 beige
    The page.
    --surface
    #ffffff light, #1d201e dark
    Fields, choice cards, the dialog, and cards on beige.
    --surface-alt
    #f1f3ee light, #252926 dark, #e7eae3 beige
    Notes.
    --text
    #1c201d light, #e4e7e2 dark
    Text.
    --muted
    #616862 light, #9ba09a dark
    Secondary text, markers, labels.
    --line
    #e4e7e0 light, #2a2e2b dark, #dfe3db beige
    Rules: table rows, entry lists, fact sheets, <hr>.
    --line-card
    #d9ddd5 light, #343936 dark, var(--line) beige, in both modes
    The outline of cards and choice cards.
    --line-strong
    #818882 light, #6e746f dark
    Control boundaries, at 3:1 or more on the page: fields, checkboxes, tracks.
    --ink
    #1c201d light, #e4e7e2 dark
    The fill of a primary button.
    --on-ink
    var(--bg) in every mode
    Text on a primary button.
    --code-bg
    #f1f3ee light, #1d201e dark, #e7eae3 beige
    Code blocks.
    --code-text
    #1c201d light, #e4e7e2 dark
    Text in code blocks.

    --line-card, --code-bg and --code-text are written as light-dark() pairs; the rest get their dark values from zinc's dark-mode rules. Those rules are stronger than plain :root, so to change a neutral in dark mode, set it under both of zinc's dark selectors:

    @media (prefers-color-scheme: dark) {
  :root:not([data-mode="light"]) { --bg: #101211; }
}
:root[data-mode="dark"] { --bg: #101211; }

    Derived

    Mixed from the tokens above with color-mix(), so they follow them. You rarely need to set these.

    --accent-soft
    12% accent
    The halo around a focused text field, the <ins> tint.
    --tint
    7% text colour
    Inline code, secondary buttons, the segmented track, the file button, hover fills.
    --tint-strong
    12% text colour
    Hover on secondary buttons and the file button.
    --ink-press
    82% ink, 18% page
    Hover on a primary button.
    --danger-press
    86% danger with black; 82% with white in dark
    Hover on a danger button.
    --shadow
    Two soft layers
    The dialog, the one thing that floats.
    --ease-out
    cubic-bezier(0.23, 1, 0.32, 1)
    The switch thumb, the summary chevron, details and the dialog.
