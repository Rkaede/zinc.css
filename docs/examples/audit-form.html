    Fix these first

    Set the undecided items here to

    1. F1 High · Reproduced

      Pasting a table from a spreadsheet freezes the editor. src/editor/paste.ts:42 converts the pasted HTML on the main thread and re-parses the whole note once per cell. A 40-row paste locks the tab for about 20 seconds, and the autosave that fires afterwards writes a half-converted note.

    2. F2 High · Reproduced

      Notes edited offline are lost when sync resumes. src/sync/queue.ts:88 replays queued changes but compares them with the server copy's updatedAt, so a note edited on two devices keeps the server version and drops the local one without a conflict prompt. Reproduced by editing the same note on a laptop in flight mode and on a phone.

    3. F3 High · Read in code

      Deleted notes stay readable through shared links. Revoking a share in src/share/links.ts hides the link in the interface but never deletes the token, and GET /s/:token (server/routes/share.ts:19) doesn't check deletedAt. Anyone with an old link can still read a note its owner deleted.

    4. F4 High · Reproduced

      The formatting toolbar can't be reached by keyboard. src/editor/toolbar.ts renders its buttons as <div>s with click handlers, so Tab jumps straight from the title to the note body. Bold, lists and links have shortcuts; headings, checklists and tables have none.

    5. F5 High · Read in code

      Attachments are stored as base64 strings inside each note. src/storage/attachments.ts:31 inlines every image into the note record, so a note with three photos weighs several megabytes and every keystroke saves all of it. When the storage quota runs out, the save throws and the error is swallowed.

    Editor and formatting

    Set the undecided items here to

    1. ED1 High · Reproduced

      Undo after an autosave restores the wrong text. The history stack (src/editor/history.ts:54) is rebuilt from the saved document after each autosave, so Undo jumps back to the last save instead of the last edit. Reproduced: type two words, wait three seconds, undo, and both words disappear.

    2. ED2 Medium · Read in code

      Checklist items lose their ticks when reordered. Dragging an item calls moveBlock (src/editor/blocks.ts:120), which copies the text but not the checked attribute.

    3. ED3 Low · Read in code

      Smart quotes are applied inside code spans. The typography plugin in src/editor/typography.ts doesn't skip code marks, so straight quotes in inline code turn curly and break copied snippets.

    Import and export (src/io)

    Set the undecided items here to

    1. IO1 Medium · Reproduced

      Markdown export drops front matter. export-md.ts:22 writes only the note body, so tags, the creation date and the pinned state are lost, and re-importing the file gives a note with no tags. Reproduced with a note tagged Recipes.

    2. IO2 Low · Read in code

      The importer assumes every file is UTF-8. import.ts:9 calls file.text() without checking for a byte-order mark, so UTF-16 files from older editors come in as garbled text.

    Sync, storage and data safety

    Set the undecided items here to

    1. SY1 Medium · Read in code

      Two open tabs overwrite each other's changes. Each tab keeps its own copy of the open note and saves it whole, and nothing listens for changes from other tabs, so the last tab to save wins.

    2. SY2 Low · Reproduced

      The sync badge says Synced while changes are still queued. src/sync/status.ts sets the badge from the last response rather than the queue length, so closing the tab at that moment loses the pending edits.

    Search and navigation

    Set the undecided items here to

    1. SR1 Medium · Reproduced

      Search ignores accents in titles but not in note bodies. Titles are normalised (src/search/index.ts:47) and bodies aren't, so searching for "cafe" finds a note titled "Café list" but none of the notes that mention it.

    2. SR2 Low · Read in code

      The back button doesn't return to search results. Opening a result replaces the URL instead of pushing a new entry (src/router.ts:63), so Back leaves the app.

    Security

    Set the undecided items here to

    1. SE1 Medium · Read in code

      Pasted HTML keeps inline event handlers until the next save. The paste sanitiser strips <script> but not onerror attributes, and the live preview renders them before the save step cleans them up.

    2. SE2 Low · Read in code

      The session cookie has no SameSite attribute. server/auth/session.ts:14 relies on browser defaults. Set SameSite=Lax explicitly, and Secure in production.

    UX and copy

    Set the undecided items here to

    1. UX1 Medium · Reproduced

      Deleting a notebook deletes its notes without saying so. The dialog asks "Delete notebook?" but doesn't mention the notes inside it, and the trash keeps deleted notes but not deleted notebooks.

    2. UX2 Low · Read in code

      Copy is inconsistent:

      • "Notebook" in the sidebar, "Folder" in settings
      • "Sign in" and "Log in" on the same screen
      • "Synced" vs "Up to date"
      • "tidewater" in lower case in the About dialog
      • "Delete forever" in the trash, "Remove" everywhere else

    Mobile and responsive

    Set the undecided items here to

    1. MO1 Medium · Reproduced

      The formatting toolbar sits under the on-screen keyboard. On a 390px phone it is fixed to the bottom of the layout viewport (src/styles/toolbar.css:8) rather than the visual viewport, so it is hidden whenever you type.

    Accessibility

    Set the undecided items here to

    1. A11Y1 High · Reproduced

      Focus is lost after closing any dialog. src/ui/dialog.ts removes the dialog without returning focus to the button that opened it, so keyboard and screen reader users land at the top of the page every time.

    2. A11Y2 Medium · Reproduced

      Contrast:

      • Editor placeholder text: 2.3:1
      • Tag chips in the sidebar: 2.8:1
      • Disabled toolbar buttons look the same as enabled ones
      • Selected note in the list: about 1.2:1 against its neighbours
      • Links in dark mode: 2.6:1

    3. A11Y3 Low · Read in code

      The note list has no accessible name. src/ui/note-list.ts renders a bare <ul>, and each row announces only the title, not the date or notebook shown beside it.

    Theming and styles

    Set the undecided items here to

    1. TH1 Medium · Read in code

      Dark mode flashes white on load. src/theme.ts applies the theme after the app bundle loads. Read the stored preference in a small inline script in index.html before first paint.

    2. TH2 Low · Read in code

      Colours are hard-coded in 23 places. Most components use the variables in src/styles/tokens.css, but the editor, the tag chips and the print styles use literal hex values that ignore the theme.

    Performance

    Set the undecided items here to

    1. PF1 Medium · Reproduced

      Opening a notebook with 2,000 notes takes four seconds. src/ui/note-list.ts renders every row up front and builds a preview excerpt for each. Virtualise the list or build excerpts as rows scroll into view.

    2. PF2 Low · Read in code

      The emoji picker's data loads on startup. src/editor/emoji.ts imports a 900 KB JSON file at the top level; load it when the picker first opens.
