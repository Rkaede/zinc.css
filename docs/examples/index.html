Examples

Whole pages of the kinds zinc is built for: reports, dashboards and forms, in plain semantic HTML with no classes.

The people, companies and projects in them are invented. Add ?mode=dark, ?accent=forest or ?paper=beige to any page; a theme picked on the theming page is passed along by the links below.

  • Code health

  • Recommendations

    A long report with a folded index and many disclosures.

Boards
