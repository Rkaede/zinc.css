A specimen of every tag the framework styles, in the order a real document uses them. Force a mode with ?mode=dark, pick an accent with ?accent=forest, and switch to the beige paper with ?paper=beige.

Typography sets the tone

Body copy should read comfortably at length. It carries inline links, strong emphasis, italic asides, inline code, keyboard keys like ⌘ K, highlighted text, CSS abbreviations, removed and inserted words, H2O and E = mc2. Small print sits in a muted tone for secondary details.
